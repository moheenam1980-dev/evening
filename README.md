# أسماء الطلبة المقبولين — الدراسة المسائية
كلية علوم الحاسوب والرياضيات — جامعة الموصل

## الملفات
- `index.html` : صفحة الموقع
- `students.js` : قائمة الأسماء والأقسام (لتحديث الأسماء عدّل هذا الملف فقط)
- `logo.png` و `favicon.png` : الشعار

## النشر على GitHub Pages
1. أنشئ مستودعاً جديداً (Public) على GitHub.
2. ارفع جميع الملفات إلى جذر المستودع (Add file ← Upload files).
3. من Settings ← Pages اختر: Branch = main و Folder = / (root) ثم Save.
4. بعد دقيقة يصبح الموقع متاحاً على: `https://USERNAME.github.io/REPO-NAME/`
